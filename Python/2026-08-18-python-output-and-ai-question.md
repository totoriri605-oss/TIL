# TIL — 파이썬으로 처음 출력해 보기

## 오늘 배운 내용

오늘은 파이썬의 `print()`를 사용해서 문자와 숫자를 화면에 출력하는 방법을 배웠다.

또 코드에 오류가 생겼을 때 ChatGPT에게 어떻게 질문하면 좋은지도 배웠다.

## `print()`란?

`print()`는 괄호 안에 적은 내용을 화면에 보여 주는 기능이다.

```python
print("Hello, Python!")
```

실행 결과:

```text
Hello, Python!
```

이 코드는 쉽게 말하면 다음과 같다.

* `print`: 화면에 보여 줘
* `( )`: 보여 줄 내용을 넣는 곳
* `"Hello, Python!"`: 실제로 보여 줄 글자

## 문자와 숫자는 다르다

다음 두 코드를 실행해 보았다.

```python
print(100)
print("100")
```

화면에는 둘 다 `100`이라고 나온다.

하지만 둘은 서로 다르다.

* `100`은 숫자
* `"100"`은 글자

따옴표로 감싸면 파이썬은 그 값을 글자로 생각한다.

아직 정확한 차이를 모두 알지는 못하지만, 숫자와 글자는 파이썬에서 다르게 사용된다는 것을 알게 되었다.

## 여러 값을 같이 출력하기

쉼표를 사용하면 여러 값을 한 줄에 출력할 수 있다.

```python
print("이름:", "정민")
print("공부한 시간:", 2)
```

실행 결과:

```text
이름: 정민
공부한 시간: 2
```

문자와 숫자를 함께 보여 줄 수 있다는 것이 신기했다.

## 코드는 위에서 아래로 실행된다

다음 코드를 실행해 보았다.

```python
print("첫 번째")
print("두 번째")
print("세 번째")
```

실행 결과:

```text
첫 번째
두 번째
세 번째
```

파이썬은 기본적으로 내가 작성한 코드를 위에서 아래로 실행한다.

그래서 코드의 순서를 바꾸면 출력되는 순서도 바뀐다.

## 주석 사용하기

`#` 뒤에는 코드에 대한 설명을 적을 수 있다.

```python
# 나를 소개하는 프로그램

print("이름:", "정민")
print("목표:", "파이썬으로 웹사이트 만들기")
```

주석은 사람이 코드를 읽기 쉽게 도와주는 설명이다.
컴퓨터는 `#` 뒤의 내용을 실행하지 않는다.

## 오늘 만난 오류

닫는 괄호를 작성하지 않으면 오류가 발생한다.

```python
print("Hello, Python!"
```

이 코드를 실행하면 `SyntaxError`가 나온다.

처음에는 영어로 된 오류 메시지가 길게 나와서 당황했다. 하지만 오류 메시지에서 문제가 발생한 줄과 오류 이름을 먼저 확인하면 된다는 것을 배웠다.

오류가 났을 때는 다음 순서로 확인한다.

```text
코드 보기
→ 오류 메시지 읽기
→ 문제가 생긴 줄 찾기
→ 한 부분만 고치기
→ 다시 실행하기
```

## ChatGPT에게 질문하는 방법

처음에는 이렇게 질문하기 쉽다.

```text
코드가 안 돼. 고쳐줘.
```

하지만 이렇게 물어보면 ChatGPT는 내가 무엇을 하려는지 알기 어렵다.

앞으로는 다음 내용을 함께 보내려고 한다.

* 무엇을 만들려고 했는지
* 내가 작성한 코드
* 화면에 나온 오류
* 원래 기대한 결과
* 어떤 도움이 필요한지

예:

```text
나는 파이썬을 처음 배우고 있어.

화면에 Hello, Python!을 출력하려고 했는데
SyntaxError가 나왔어.

완성된 코드를 바로 알려 주지 말고,
내가 어디를 먼저 확인하면 되는지
힌트 하나만 알려 줘.
```

완성된 코드를 바로 받기보다 힌트를 하나씩 받은 뒤 내가 직접 고쳐 보는 것이 공부에 더 도움이 될 것 같다.

## 오늘의 정리

오늘 배운 내용은 다음과 같다.

* `print()`로 문자와 숫자를 출력할 수 있다.
* 따옴표 안에 있는 내용은 글자로 처리된다.
* 쉼표를 사용하면 여러 값을 같이 출력할 수 있다.
* 파이썬 코드는 위에서 아래로 실행된다.
* `#` 뒤에는 설명을 적을 수 있다.
* 오류가 나면 오류 이름과 문제가 생긴 줄을 확인한다.
* ChatGPT에게 질문할 때는 코드와 오류 내용을 같이 알려 준다.

## 오늘의 한 줄

> 코드를 바로 고쳐 달라고 하기보다, 오류를 먼저 살펴보고 힌트를 받아 직접 수정해 보자.
