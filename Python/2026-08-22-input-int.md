# TIL — input()과 int() 이해하기

## 오늘 배운 내용

오늘은 `input()`으로 사용자에게 값을 입력받는 방법과, 입력받은 값을 `int()`로 숫자로 바꾸는 방법을 배웠다.

처음에는 숫자를 입력하면 당연히 숫자로 저장되는 줄 알았는데, `input()`으로 받은 값은 기본적으로 문자열(`str`)이라는 점이 가장 헷갈렸다.

## 교수님 문제

> 두 개의 숫자를 입력받아서 합계를 출력하는 프로그램을 작성하시오.

처음에는 문제 문장이 조금 어렵게 느껴졌지만, 쉽게 풀어보면 다음 순서였다.

```text
첫 번째 숫자 입력받기
→ 두 번째 숫자 입력받기
→ 두 숫자 더하기
→ 결과 출력하기
```

## input()은 무엇을 할까?

`input()`은 사용자가 키보드로 값을 입력할 수 있게 해준다.

```python
number = input("첫 번째 숫자를 입력하세요: ")
```

사용자가 `10`을 입력하면 `number`에 값이 저장된다.

하지만 여기서 중요한 점이 있다.

`input()`으로 받은 값은 숫자처럼 보여도 기본적으로 문자열(`str`)이다.

즉,

```text
10 입력
→ input()
→ "10"
```

처럼 생각하면 된다.

## 내가 헷갈렸던 문제

다음 코드를 보고 결과를 예상해 보았다.

```python
number1 = input("첫 번째 숫자: ")
number2 = input("두 번째 숫자: ")

print(number1 + number2)
```

첫 번째 숫자로 `10`, 두 번째 숫자로 `20`을 입력하면 나는 처음에 결과가 `30`이라고 생각했다.

하지만 실제 결과는 다음과 같다.

```text
1020
```

왜냐하면 `number1`과 `number2`에는 실제로 다음 값이 들어 있기 때문이다.

```text
number1 → "10"
number2 → "20"
```

따라서 파이썬은 숫자 계산인

```text
10 + 20
```

을 하는 것이 아니라 문자열인

```text
"10" + "20"
```

을 처리한다.

문자열에서 `+`는 글자를 이어 붙이는 역할을 하기 때문에 결과가 `1020`이 된다.

## 숫자 계산을 하려면 int()가 필요하다

두 값을 실제 숫자로 더하려면 `int()`를 사용해서 문자열을 정수로 바꿔야 한다.

```python
number1 = int(input("첫 번째 숫자: "))
number2 = int(input("두 번째 숫자: "))

print(number1 + number2)
```

`10`과 `20`을 입력하면 이번에는 결과가 다음과 같이 나온다.

```text
30
```

## int(input()) 실행 순서

처음에는 아래 코드가 복잡해 보였다.

```python
number = int(input("숫자를 입력하세요: "))
```

하지만 안쪽부터 보면 이해하기 쉽다.

사용자가 `10`을 입력했다고 하면:

```text
input()
→ "10"      # 문자열
→ int()
→ 10         # 정수
→ number에 저장
```

쉽게 말하면:

* `input()` : 값을 입력받아
* `int()` : 그 값을 정수로 바꿔
* `number =` : 바꾼 값을 변수에 저장해

라고 이해했다.

## 교수님 문제 완성

```python
# 첫 번째 숫자 입력받기
first_num = int(input("첫 번째 숫자 : "))

# 두 번째 숫자 입력받기
second_num = int(input("두 번째 숫자 : "))

# 두 숫자를 더하기
result = first_num + second_num

# 결과 출력하기
print(f"{first_num} 더하기 {second_num}은 {result} 입니다.")
```

예를 들어 `2`와 `5`를 입력하면:

```text
첫 번째 숫자 : 2
두 번째 숫자 : 5
2 더하기 5은 7 입니다.
```

처럼 출력된다.

## 오늘 만난 오류

코드를 따라 작성하다가 괄호가 맞지 않아 `SyntaxError`가 발생했다.

실수한 형태는 이런 식이었다.

```python
first_num = int(input(input("첫 번째 숫자 : "))
```

`input()`을 실수로 두 번 넣었고 괄호의 짝도 맞지 않았다.

오류 메시지에서 다음 문장을 확인했다.

```text
SyntaxError: closing parenthesis ... does not match opening parenthesis
```

쉽게 말하면 괄호의 짝이 맞지 않는다는 뜻이었다.

수정한 뒤 다시 실행해서 정상적으로 결과가 나오는 것을 확인했다.

## 스스로 확인 문제

다음 코드에서 `10`과 `20`을 입력하면 결과는 무엇일까?

```python
number1 = input("첫 번째 숫자: ")
number2 = input("두 번째 숫자: ")

print(number1 + number2)
```

정답은 `1020`이다.

힌트는 `input()`으로 입력받은 값의 자료형을 생각하는 것이다.

이번에는 다음 코드라면?

```python
number1 = int(input("첫 번째 숫자: "))
number2 = int(input("두 번째 숫자: "))

print(number1 + number2)
```

정답은 `30`이다.

## 오늘의 정리

* `input()`은 사용자에게 값을 입력받는다.
* `input()`으로 받은 값은 기본적으로 문자열(`str`)이다.
* 숫자처럼 보이는 `10`을 입력해도 처음에는 `"10"`으로 저장된다.
* 문자열끼리 `+`를 사용하면 숫자 계산이 아니라 글자를 이어 붙인다.
* 숫자 계산을 하려면 `int()` 등을 사용해서 숫자로 변환해야 한다.
* `int(input(...))`은 안쪽의 `input()`부터 실행된다.
* 오류가 발생하면 오류 이름과 괄호의 짝을 먼저 확인해 본다.

## 오늘의 한 줄

> `input()`은 입력값을 문자열로 받고, 숫자 계산이 필요하면 `int()` 등을 사용해 숫자로 변환해야 한다.

아직 파이썬을 처음 배우는 단계라 코드를 외우기보다는,

```text
코드 보고 결과 예상하기
→ 직접 실행하기
→ 틀린 이유 확인하기
→ 다시 수정하기
```

순서로 하나씩 이해해 보려고 한다.
