# 2026-08-26 TIL — 튜플과 집합

## 오늘 배운 내용

오늘은 여러 값을 저장하는 자료형인 **리스트, 튜플, 집합**의 차이를 공부했다.

처음에는 세 가지가 모두 여러 값을 담는다는 점 때문에 헷갈렸지만, 각각 사용하는 목적이 다르다는 것을 알게 되었다.

| 자료형 | 만드는 방법 | 특징 |
|---|---|---|
| 리스트 | `[ ]` | 순서가 있고 값을 수정할 수 있다. |
| 튜플 | `( )` | 순서가 있지만 값을 직접 수정할 수 없다. |
| 집합 | `{ }` | 중복을 허용하지 않고 고정된 순서가 없다. |

## 1. 튜플

튜플은 여러 값을 순서대로 저장하지만, 만든 뒤에는 안의 값을 직접 수정할 수 없다.

```python
colors = ("red", "green", "blue")

print(colors[0])
```

실행 결과:

```text
red
```

튜플도 리스트처럼 인덱싱을 이용해 값을 꺼낼 수 있다. 인덱스는 `0`부터 시작한다.

```python
print(colors[-1])
```

`-1`은 마지막 위치를 뜻하므로 `"blue"`가 출력된다.

하지만 다음처럼 튜플의 값을 직접 바꾸려고 하면 `TypeError`가 발생한다.

```python
colors[0] = "black"
```

## 2. 튜플 패킹과 언패킹

여러 값을 하나의 튜플로 묶는 것을 **패킹**이라고 한다.

```python
student = ("문길동", 20, "Python", "남자")
```

튜플의 값을 여러 변수에 나누어 저장하는 것을 **언패킹**이라고 한다.

```python
name, age, language, gender = student
```

값은 왼쪽부터 순서대로 저장된다.

```text
name     ← "문길동"
age      ← 20
language ← "Python"
gender   ← "남자"
```

언패킹할 때는 튜플의 값 개수와 변수의 개수가 같아야 한다.

## 3. 집합

집합은 같은 값이 여러 번 들어 있어도 하나만 남긴다.

```python
tags = ["Python", "AI", "Python", "Data", "AI"]

unique_tags = set(tags)

print(unique_tags)
```

실행 결과에는 `"Python"`, `"AI"`, `"Data"`만 하나씩 남는다.

```text
{'Python', 'AI', 'Data'}
```

집합은 순서가 고정되어 있지 않기 때문에 출력 순서가 달라질 수 있다. 또한 리스트나 튜플처럼 다음 코드를 사용할 수 없다.

```python
unique_tags[0]
```

집합에는 `0번`, `1번`과 같은 고정된 위치 번호가 없기 때문이다.

## 오늘 발생한 오류

문자열인 `"남자"`에 따옴표를 쓰지 않아 오류가 발생했다.

```python
student = ("문길동", 20, "Python", 남자)
```

파이썬은 따옴표가 없는 `남자`를 변수 이름으로 판단했다. 다음처럼 따옴표를 붙여 수정했다.

```python
student = ("문길동", 20, "Python", "남자")
```

또한 괄호를 제대로 닫지 않아 `SyntaxError`가 발생했다.

```python
print(type(len(tags))
```

괄호의 개수를 확인하고, 확인하려는 목적에 맞게 코드를 나누었다.

```python
print(type(tags))
print(len(tags))
```

## 오늘의 한 줄 정리

**리스트는 수정할 수 있고, 튜플은 수정할 수 없으며, 집합은 중복된 값을 하나만 남긴다.**
