# TIL — 처음 만나는 파이썬

## 오늘 배운 내용

오늘은 파이썬 기초를 처음 배웠다.

AI가 코드를 만들어 주더라도 코드를 읽고, 실행하고, 결과가 맞는지 확인하려면 파이썬의 기본 문법을 이해해야 한다는 것을 배웠다.

## `print()`로 값 출력하기

`print()`는 괄호 안에 작성한 값을 화면에 출력한다.

```python
print("Hello, Python!")
print(100)
```

실행 결과:

```text
Hello, Python!
100
```

문자열에는 따옴표를 사용하지만 숫자에는 따옴표를 사용하지 않는다.

## 변수를 이용한 가격 계산

```python
price = 12000
quantity = 3

total_price = price * quantity

print(total_price)
```

실행 결과:

```text
36000
```

가격과 수량을 각각 변수에 저장하고, 두 값을 곱한 결과를 `total_price`에 저장했다.

## 오늘 발생한 오류

처음에는 다음과 같이 작성했다.

```python
total_price = price * quantity
print(total)
```

발생한 오류:

```text
NameError: name 'total' is not defined
```

## 오류의 원인과 해결

계산 결과를 `total_price`라는 변수에 저장했지만, 출력할 때 존재하지 않는 `total`을 사용해서 오류가 발생했다.

다음과 같이 변수 이름을 동일하게 수정했다.

```python
print(total_price)
```

수정 후 코드가 정상적으로 실행됐다.

## 오늘 새롭게 이해한 점

- `print()`를 사용하면 문자와 숫자를 화면에 출력할 수 있다.
- 변수에는 값을 저장할 수 있다.
- 변수 이름은 저장할 때와 사용할 때 동일해야 한다.
- 오류 메시지에는 문제를 해결할 수 있는 단서가 들어 있다.
- 코드는 직접 실행하고 결과를 확인해야 정확히 이해할 수 있다.

## 오늘의 한 줄 정리

> AI에게 정답만 받기보다 코드를 직접 실행하고 수정하며 결과를 확인하자.

## 프로그래밍의 기본 흐름

프로그래밍은 컴퓨터가 해야 할 일과 순서를 명확하게 설명하는 과정이다.

프로그램의 기본 흐름은 다음과 같다.

```text
입력(Input)
→ 처리(Process)
→ 출력(Output)
```

상품 주문 금액을 계산하는 경우에는 다음과 같이 나눌 수 있다.

- 입력: 상품 가격과 수량
- 처리: 가격과 수량을 곱하기
- 출력: 총 주문 금액 보여 주기

문제를 바로 코드로 작성하기 전에 입력, 처리, 출력으로 나누어 생각하면 전체 흐름을 이해하기 쉽다.

## 파이썬의 활용 분야

파이썬은 사람이 비교적 읽기 쉬운 프로그래밍 언어이며 다음과 같은 분야에서 활용할 수 있다.

- 데이터 분석
- AI와 머신러닝
- 웹·백엔드 개발
- 업무 자동화

나는 앞으로 파이썬과 Django를 활용해 학습 퀴즈 사이트와 고객관리 웹사이트를 만들어 보고 싶다.

## 사람과 AI의 역할

사람은 해결할 문제와 필요한 결과를 정하고, AI가 만든 코드를 직접 실행한 뒤 결과가 맞는지 판단해야 한다.

AI는 다음과 같은 부분을 도와줄 수 있다.

- 어려운 개념을 쉽게 설명하기
- 짧은 예제 코드 제안하기
- 오류 메시지 분석하기
- 코드 개선 방법 제안하기
- 다음 단계의 힌트 제공하기

사람은 방향과 판단을 담당하고, AI는 설명과 제안, 검토를 지원한다.

## AI에게 좋은 질문을 하는 방법

AI에게 질문할 때는 다음 내용을 구체적으로 전달해야 한다.

1. 현재 나의 수준과 상황
2. 배우거나 해결하려는 목표
3. 현재 작성한 코드 또는 오류
4. 설명, 힌트, 검토 중 원하는 도움

예:

```text
나는 파이썬을 처음 배우고 있어.

완성 코드를 다시 작성하지 말고,
내 코드에서 문제가 되는 부분을
한 가지씩 힌트로 알려 줘.
```
